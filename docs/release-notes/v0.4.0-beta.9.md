# Rekamind v0.4.0-beta.9

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

The server address in Settings now keeps its path. Any domain works, with or without a subdomain, port or sub-path (`https://rekamind.kantor.id`, `https://rapat.tim.kantor.id:8443`, `https://kantor.id/playground/rekamind`).

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.9-cpu`, `-cuda`, `-cuda-diarize`, or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Fix: a server address with a path was cut to its domain.** `https://host/playground/rekamind/` was saved as `https://host`, so the app could not reach the server. The path is now kept (query, fragment and trailing slash are dropped).
- **Sub-path deployment of the web UI** (`REKAMIND_BASE`) and sign-in cookies scoped to the path of `REKAMIND_PUBLIC_URL`, as built in beta.8.

## Known limitations
- Same limits as beta.7 (uploads over 100 MB behind Cloudflare's free plan, the daily summary quota).
- After updating, open Settings and save the server address again; an address saved by an older version has no path.

# Rekamind v0.4.0-beta.9 (Bahasa Indonesia)

Alamat server di Pengaturan kini mempertahankan path-nya. Domain apa pun bisa dipakai, dengan atau tanpa subdomain, port, atau sub-path.

## Yang berubah
- **Perbaikan: alamat server dengan path terpotong jadi domainnya saja.** Path kini dipertahankan (query, fragment, dan garis miring di akhir dibuang).
- **Penyajian UI web di sub-path** (`REKAMIND_BASE`) dan cookie masuk yang dibatasi ke path `REKAMIND_PUBLIC_URL`, seperti di beta.8.

## Batasan yang diketahui
- Batasan lain sama seperti beta.7.
- Setelah memperbarui, buka Pengaturan dan simpan ulang alamat server; alamat yang disimpan versi lama tidak punya path.
