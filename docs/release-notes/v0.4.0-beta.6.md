# Rekamind v0.4.0-beta.6

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

Mostly for people who run the **server in Docker**. Running beta.5 on a real GPU server showed that the very first
transcription could hang while downloading the Whisper model; that is fixed. There is also a new server image with
**speaker separation** for NVIDIA GPUs. The desktop app is unchanged apart from its version number, so this release is also
the first real test of the in-app update from beta.5.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.6-cpu` (CPU), `-cuda` (NVIDIA GPU), `-cuda-diarize` (NVIDIA GPU + speaker separation, new), or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Fixed: the first transcription on a fresh server stalled while downloading the Whisper model.** On a real server the `large-v3` download stopped after about 130 MB although the network ran at about 110 MB/s. Hugging Face's Xet downloader was the suspect. The image and the compose files now set `HF_HUB_DISABLE_XET=1`; with it the 3 GB download finished in under two minutes. **If you already run a stack, add `HF_HUB_DISABLE_XET: "1"` under `environment:`.**
- **New: `-cuda-diarize` image** (NVIDIA GPU + pyannote). Use it with `REKAMIND_DIARIZER=pyannote` and `REKAMIND_HF_TOKEN` (a Hugging Face token whose account accepted the terms of the `pyannote/speaker-diarization-3.1` and `pyannote/segmentation-3.0` models). CI builds it and checks that its libraries import, but **it has not run on a GPU yet.**
- **Compose files:** they now also pass `REKAMIND_DIARIZER`, `REKAMIND_HF_TOKEN`, `REKAMIND_WHISPER_COMPUTE_TYPE`, `REKAMIND_GLOSSARY`, `REKAMIND_MAX_UPLOAD_MB`, `REKAMIND_LLM_CHUNK_CHARS` and `REKAMIND_BIND`, so you set them in the variables panel instead of editing the YAML.
- **Behaviour change: the compose files now publish the port on all interfaces (`0.0.0.0`), not `127.0.0.1`,** so a reverse proxy on another host can reach it. Allow it only from that proxy in the firewall, or set `REKAMIND_BIND=127.0.0.1` when the proxy runs on the same host.
- **Measured:** on an RTX 4060 Ti (16 GB), one short recording, Whisper `large-v3` used about 4.1 GB of VRAM at its peak and gave it back when the queue emptied (within about 130 MB of idle).

## Known limitations
- The `-cuda-diarize` image is new and untested on a GPU; the extra VRAM for pyannote (about 1-2 GB) is an estimate. Speaker separation on AMD/Intel GPUs and in the other images is unchanged.
- The VRAM figures come from one short recording on one GPU; a long meeting may use more.
- The in-app update (beta.5 → beta.6) downloads and verifies the installer, but running it and restarting the app has not been tested end to end. If the app does not reopen by itself, start it from the Start menu.
- Installers are **unsigned**. Linux desktop and the AppImage are untested/not working, as before.
- Everything under the limitations of v0.4.0-beta.4 still applies.

Report problems through Issues (do not attach recordings or API keys).

# Bahasa Indonesia

Terutama untuk yang menjalankan **server di Docker**. Menjalankan beta.5 di server GPU sungguhan menunjukkan bahwa transkripsi
pertama bisa menggantung saat mengunduh model Whisper; itu sudah diperbaiki. Ada juga image server baru dengan
**pemisah pembicara** untuk GPU NVIDIA. Aplikasi desktop tidak berubah selain nomor versinya, jadi rilis ini sekaligus uji
nyata pertama pembaruan dalam aplikasi dari beta.5.

## Unduh

| Sistem | Berkas |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, distro lain | `Rekamind-Linux-x64.AppImage` (hanya bila terlampir; build AppImage sejauh ini belum berhasil) |

**Image server (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.6-cpu` (CPU), `-cuda` (GPU NVIDIA), `-cuda-diarize` (GPU NVIDIA + pemisah pembicara, baru), atau tanpa akhiran (hanya API).

Verifikasi dengan `SHA256SUMS.txt`. **Installer belum bertanda tangan.** Windows SmartScreen akan memperingatkan: *More info → Run anyway*.

## Yang berubah
- **Diperbaiki: transkripsi pertama di server baru menggantung saat mengunduh model Whisper.** Di server sungguhan unduhan `large-v3` berhenti sekitar 130 MB padahal jaringan berjalan ±110 MB/s. Pengunduh Xet milik Hugging Face dicurigai. Image dan berkas compose kini mengatur `HF_HUB_DISABLE_XET=1`; dengan itu unduhan 3 GB selesai dalam kurang dari dua menit. **Bila Anda sudah menjalankan stack, tambahkan `HF_HUB_DISABLE_XET: "1"` di bawah `environment:`.**
- **Baru: image `-cuda-diarize`** (GPU NVIDIA + pyannote). Pakai dengan `REKAMIND_DIARIZER=pyannote` dan `REKAMIND_HF_TOKEN` (token Hugging Face yang akunnya sudah menerima syarat model `pyannote/speaker-diarization-3.1` dan `pyannote/segmentation-3.0`). CI membangunnya dan memeriksa pustakanya bisa diimpor, tetapi **belum pernah dijalankan di GPU.**
- **Berkas compose:** kini juga meneruskan `REKAMIND_DIARIZER`, `REKAMIND_HF_TOKEN`, `REKAMIND_WHISPER_COMPUTE_TYPE`, `REKAMIND_GLOSSARY`, `REKAMIND_MAX_UPLOAD_MB`, `REKAMIND_LLM_CHUNK_CHARS`, dan `REKAMIND_BIND`, jadi cukup diisi di panel variabel tanpa mengedit YAML.
- **Perubahan perilaku: berkas compose kini membuka port di semua antarmuka (`0.0.0.0`), bukan `127.0.0.1`,** supaya reverse proxy di host lain bisa menjangkaunya. Izinkan hanya dari proxy itu di firewall, atau isi `REKAMIND_BIND=127.0.0.1` bila proxy berjalan di host yang sama.
- **Diukur:** di RTX 4060 Ti (16 GB), satu rekaman pendek, Whisper `large-v3` memakai sekitar 4,1 GB VRAM pada puncaknya dan melepasnya saat antrean kosong (dalam ±130 MB dari kondisi idle).

## Batasan yang diketahui
- Image `-cuda-diarize` baru dan belum diuji di GPU; tambahan VRAM untuk pyannote (sekitar 1-2 GB) adalah perkiraan. Pemisah pembicara di GPU AMD/Intel dan di image lain tidak berubah.
- Angka VRAM berasal dari satu rekaman pendek di satu GPU; rapat panjang bisa memakai lebih banyak.
- Pembaruan dalam aplikasi (beta.5 → beta.6) mengunduh dan memverifikasi installer, tetapi menjalankannya dan membuka ulang aplikasi belum diuji dari awal sampai akhir. Bila aplikasi tidak terbuka sendiri, buka dari menu Start.
- Installer **belum bertanda tangan**. Desktop Linux dan AppImage belum diuji/belum berfungsi, seperti sebelumnya.
- Semua batasan pada v0.4.0-beta.4 masih berlaku.

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
