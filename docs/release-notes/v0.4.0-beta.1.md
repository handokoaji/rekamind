# Rekamind v0.4.0-beta.1

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

First release of the new generation (v2): a light desktop recorder, per-speaker transcripts, summaries and tasks.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (if attached) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.1-cpu` (CPU), `-cuda` (NVIDIA GPU), or without suffix (API only). Compose files: `docker-compose.image.yml`, `docker-compose.image-gpu.yml`.

Verify with `SHA256SUMS.txt`. Install-to-first-use guide: [README](https://github.com/handokoaji/rekamind#-guide-from-install-to-first-use).

**The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What is included
- Microphone + system-audio recorder (Windows WASAPI, Linux PulseAudio/PipeWire), `Ctrl+Alt+R`.
- Bundled local backend (no Python needed); the transcription engine (CPU/NVIDIA) is installed once from Settings.
- Per-speaker transcript, summary, decisions, flow of the meeting, tasks with evidence quotes.
- Export to Word/Markdown/JSON; send tasks to GitHub, GitLab or a signed webhook.
- Time zone (default WIB). Shared server with Google sign-in (Docker).

## Known limitations
- Installers are unsigned.
- **Linux desktop (tray, hotkey, audio) has not been tested on a real machine.**
- Windows: tested on one PC. Long recordings with the window closed, force-kill, real Word and Credential Manager are still being tested manually.
- **GPU: only CPU and NVIDIA CUDA. AMD and Intel GPUs are not supported and have never been tested** (they run on the CPU).
- Real GitHub/GitLab/Google/S3 have only been tested against mock servers.
- Transcript/summary/task quality has not been measured widely. Review the output.
- Interface: Indonesian (default) and English. Generated summaries/tasks are Indonesian only.

## Roadmap (not implemented yet)
- Intel GPU acceleration (incl. integrated, e.g. Core Ultra 7 155H); AMD GPU acceleration (incl. integrated).
- More interface languages, and a choice of output language.

Report problems through Issues (do not attach recordings or API keys).

## Isi
- Perekam mikrofon + suara sistem (Windows WASAPI, Linux PulseAudio/PipeWire), `Ctrl+Alt+R`.
- Backend lokal dibundel (tanpa Python); mesin transkripsi (CPU/NVIDIA) dipasang sekali dari Pengaturan.
- Transkrip per pembicara, ringkasan, keputusan, jalannya rapat, task dengan kutipan bukti.
- Ekspor Word/Markdown/JSON; kirim task ke GitHub, GitLab, atau webhook bertanda tangan.
- Zona waktu (bawaan WIB). Server bersama dengan login Google (Docker).

## Batasan yang diketahui
- Installer tidak bertanda tangan.
- **Linux desktop (baki, hotkey, audio) belum diuji di mesin sungguhan.**
- Windows: diuji di satu PC. Rekam panjang saat jendela tertutup, mati paksa, Word asli, dan Credential Manager masih diuji manual.
- **GPU: hanya CPU dan NVIDIA CUDA. GPU AMD dan Intel belum didukung dan belum pernah diuji** (berjalan di CPU).
- GitHub/GitLab/Google/S3 asli baru diuji dengan server tiruan.
- Kualitas transkrip/ringkasan/task belum diukur luas. Tinjau hasilnya.
- Antarmuka: Indonesia (bawaan) dan Inggris. Ringkasan/task yang dihasilkan hanya berbahasa Indonesia.

## Peta jalan (belum dikerjakan)
- Akselerasi GPU Intel (termasuk terintegrasi, mis. Core Ultra 7 155H); akselerasi GPU AMD (termasuk terintegrasi).
- Lebih banyak bahasa antarmuka, dan pilihan bahasa keluaran.

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
