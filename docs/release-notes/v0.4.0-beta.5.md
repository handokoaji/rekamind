# Rekamind v0.4.0-beta.5

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

Aimed at people who use the desktop app with a **separate server** (Docker/Portainer). Sign-in to a server whose
certificate chains through Google Trust Services failed after the browser step; that is fixed, the "cannot reach the
server" screen no longer traps you, and the app can now tell you when a newer version is out. If you only use the app in
local mode, nothing changes for you except the update notice.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.5-cpu` (CPU), `-cuda` (NVIDIA GPU), or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Fixed: desktop sign-in failed with `native-tls: unable to find any user-specified roots in the final cert chain`.** The Google sign-in in the browser worked, then the app's own call to the server was rejected. The app trusted only a built-in set of certificate roots; it now trusts the Windows certificate store, like your browser. Checked against a real server behind Google Trust Services certificates.
- **Fixed: stuck on "Tidak dapat terhubung ke server".** That screen told you to open Settings, which was behind the sign-in. It now offers **Pakai mode lokal** (one click back to local mode, other settings kept) and **Ubah pengaturan server**.
- **New: update notice.** The desktop app checks GitHub Releases shortly after start and every 6 hours. When a newer release exists, a banner on the meetings page offers **Perbarui sekarang**: the installer is downloaded, checked against the release's `SHA256SUMS.txt` (a mismatch installs nothing), run, and Rekamind restarts. It is refused while a recording, an upload or an engine install is running. A beta is only offered to someone already on a beta. On Linux the button opens the release page.
- **Server compose files:** `REKAMIND_CORS_ORIGINS` now defaults to the desktop app's origins. **If you already deployed a stack, add that variable** (`http://tauri.localhost,https://tauri.localhost,tauri://localhost`) or the desktop app will keep saying it cannot reach the server.

## Known limitations
- **Updating from beta.4 to beta.5 is manual** (install this release over the old one). The in-app update starts working from beta.5 onward.
- The in-app updater downloads and verifies the installer (tested against the real v0.4.0-beta.4 release), but **running the installer and restarting the app has not been tested end to end**; the installer flags are the ones Tauri's NSIS installer documents. If the app does not reopen by itself, start it from the Start menu.
- The installer is **unsigned**; the update's integrity rests on GitHub's HTTPS and on who can publish releases in this repository, plus the SHA-256 check. A signed update channel is future work.
- The server image changed only in its compose defaults; there is no new server behaviour.
- Everything listed under the limitations of v0.4.0-beta.4 still applies (AMD/Intel GPUs experimental, Linux desktop untested, installers unsigned).

Report problems through Issues (do not attach recordings or API keys).

# Bahasa Indonesia

Ditujukan untuk pengguna aplikasi desktop dengan **server terpisah** (Docker/Portainer). Masuk ke server yang sertifikatnya
berantai lewat Google Trust Services gagal setelah langkah di browser; itu sudah diperbaiki, layar "tidak dapat terhubung ke server"
tidak lagi mengunci Anda, dan aplikasi kini bisa memberi tahu bila ada versi baru. Bila Anda hanya memakai mode lokal, tidak ada
yang berubah selain pemberitahuan pembaruan.

## Unduh

| Sistem | Berkas |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, distro lain | `Rekamind-Linux-x64.AppImage` (hanya bila terlampir; build AppImage sejauh ini belum berhasil) |

**Image server (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.5-cpu` (CPU), `-cuda` (GPU NVIDIA), atau tanpa akhiran (hanya API).

Verifikasi dengan `SHA256SUMS.txt`. **Installer belum bertanda tangan.** Windows SmartScreen akan memperingatkan: *More info → Run anyway*.

## Yang berubah
- **Diperbaiki: masuk dari aplikasi desktop gagal dengan `native-tls: unable to find any user-specified roots in the final cert chain`.** Login Google di browser berhasil, lalu panggilan aplikasi sendiri ke server ditolak. Aplikasi hanya memercayai kumpulan akar sertifikat bawaan; kini ia memercayai penyimpanan sertifikat Windows, seperti browser Anda. Diperiksa terhadap server sungguhan dengan sertifikat Google Trust Services.
- **Diperbaiki: terkunci di "Tidak dapat terhubung ke server".** Layar itu menyuruh membuka Pengaturan, padahal Pengaturan ada di balik login. Kini tersedia **Pakai mode lokal** (satu klik kembali ke mode lokal, pengaturan lain tetap) dan **Ubah pengaturan server**.
- **Baru: pemberitahuan pembaruan.** Aplikasi desktop memeriksa GitHub Releases sesaat setelah dibuka dan tiap 6 jam. Bila ada rilis lebih baru, spanduk di halaman rapat menawarkan **Perbarui sekarang**: installer diunduh, dicocokkan dengan `SHA256SUMS.txt` rilis itu (tidak cocok berarti tidak ada yang dipasang), dijalankan, lalu Rekamind dibuka ulang. Ditolak selama ada rekaman, unggahan, atau pemasangan mesin yang berjalan. Beta hanya ditawarkan kepada yang sudah memakai beta. Di Linux tombolnya membuka halaman rilis.
- **Berkas compose server:** `REKAMIND_CORS_ORIGINS` kini bawaannya berisi origin aplikasi desktop. **Bila Anda sudah men-deploy stack, tambahkan variabel itu** (`http://tauri.localhost,https://tauri.localhost,tauri://localhost`) atau aplikasi desktop tetap mengaku tidak bisa menghubungi server.

## Batasan yang diketahui
- **Pembaruan beta.4 ke beta.5 dilakukan manual** (pasang rilis ini di atas yang lama). Pembaruan dalam aplikasi mulai bekerja dari beta.5.
- Pembaruan dalam aplikasi mengunduh dan memverifikasi installer (diuji terhadap rilis v0.4.0-beta.4 yang asli), tetapi **menjalankan installer dan membuka ulang aplikasi belum diuji dari awal sampai akhir**; flag installer mengikuti dokumentasi installer NSIS Tauri. Bila aplikasi tidak terbuka sendiri, buka dari menu Start.
- Installer **belum bertanda tangan**; keutuhan pembaruan bertumpu pada HTTPS GitHub dan pada siapa yang boleh menerbitkan rilis di repositori ini, ditambah pemeriksaan SHA-256. Jalur pembaruan bertanda tangan masih pekerjaan mendatang.
- Image server hanya berubah pada bawaan compose; tidak ada perilaku server baru.
- Semua batasan pada v0.4.0-beta.4 masih berlaku (GPU AMD/Intel eksperimental, desktop Linux belum diuji, installer tidak bertanda tangan).

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
