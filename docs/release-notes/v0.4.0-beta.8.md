# Rekamind v0.4.0-beta.8

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

A small release: the web UI can be served under a sub-path behind a reverse proxy, for example `https://apps.ugm.ac.id/playground/rekamind/`. Nothing changes for the desktop app or for a server at the root of its own domain.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.8-cpu` (CPU), `-cuda` (NVIDIA GPU), `-cuda-diarize` (NVIDIA GPU + speaker separation), or without suffix (API only). New: `0.4.0-beta.8-cuda-diarize-playground`, the same as `-cuda-diarize` with the UI built for `/playground/rekamind/`.

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Sub-path deployment.** Build the UI with `REKAMIND_BASE=/playground/rekamind/` (Docker: `--build-arg REKAMIND_BASE=...`). Assets, router, API calls, the sign-in link and sign-out all follow it. The proxy must strip the prefix before the backend.
- **Fix: Google sign-in behind a stripped prefix.** The sign-in cookies are now scoped to the path of `REKAMIND_PUBLIC_URL`. Set `REKAMIND_PUBLIC_URL=https://apps.ugm.ac.id/playground/rekamind` and register `.../auth/callback` under that path in the Google OAuth client.

## Known limitations
- The `-playground` image is the only one built for the sub-path; it no longer works when opened directly on port 8787.
- Same limits as beta.7 (uploads over 100 MB behind Cloudflare's free plan, the daily summary quota, judging topics on your own meetings).
- This sub-path setup has been tested with the production build and the unit tests, not yet end to end behind the real proxy.

# Rekamind v0.4.0-beta.8 (Bahasa Indonesia)

Rilis kecil: UI web bisa disajikan di sub-path di belakang reverse proxy, misalnya `https://apps.ugm.ac.id/playground/rekamind/`. Tidak ada perubahan untuk aplikasi desktop atau server yang berada di root domainnya sendiri.

## Yang berubah
- **Penyajian di sub-path.** Bangun UI dengan `REKAMIND_BASE=/playground/rekamind/` (Docker: `--build-arg REKAMIND_BASE=...`). Aset, router, panggilan API, tautan masuk, dan keluar mengikutinya. Proxy harus membuang prefix sebelum ke backend.
- **Perbaikan: masuk dengan Google di belakang prefix yang dibuang.** Cookie masuk sekarang dibatasi ke path `REKAMIND_PUBLIC_URL`. Isi `REKAMIND_PUBLIC_URL=https://apps.ugm.ac.id/playground/rekamind` dan daftarkan `.../auth/callback` di path itu pada OAuth client Google.
- **Image baru** `0.4.0-beta.8-cuda-diarize-playground`: sama dengan `-cuda-diarize`, dengan UI untuk `/playground/rekamind/`.

## Batasan yang diketahui
- Image `-playground` tidak lagi berfungsi bila dibuka langsung di port 8787.
- Batasan lain sama seperti beta.7.
- Setelan sub-path ini baru diuji dengan build produksi dan tes unit, belum menyeluruh di belakang proxy yang sebenarnya.
