# Rekamind v0.4.0-beta.4

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

**New licence: AGPL-3.0-or-later** (earlier releases were MIT). Also aimed at AMD GPU users. The AMD (Vulkan) engine from beta.2 has now been run on real hardware, and the
**Uji mesin** (Test engine) button no longer wrongly reports "no Vulkan device". If you use the CPU or an NVIDIA GPU, nothing
changes for you.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.4-cpu` (CPU), `-cuda` (NVIDIA GPU), or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Licence:** Rekamind is now **AGPL-3.0-or-later** (whole repository). Using, installing and modifying it stays free; if you run a modified version as a network service you must offer its source to that service's users. Earlier releases were published under MIT. See [THIRD_PARTY_NOTICES.md](https://github.com/handokoaji/rekamind/blob/master/THIRD_PARTY_NOTICES.md) for third-party components and model attributions.
- **Fixed:** on AMD, **Uji mesin** said "Tidak ada perangkat Vulkan; memakai CPU" although real transcription used the GPU. The test could not see the GPU because it silenced whisper.cpp's log; it now reports the device (e.g. `AMD Radeon(TM) 860M Graphics`).
- **Tested (experimental, one machine):** AMD GPU via Vulkan on a **Ryzen AI 7 350 (Radeon 860M, Windows 11)**. A real ~11 minute recording was transcribed on the GPU (`large-v3` q5_0): about 3 minutes for the computer-audio track, ~85% GPU use and ~2.4 GB RAM peak, read from Task Manager and the process list. The backend log shows `whisper.cpp memakai GPU Vulkan: <name>`.
- **Docs:** README (EN/ID) states the AMD status and its limits plainly.

## Known limitations
- Installers are unsigned. **Linux desktop (tray, hotkey, audio) has not been tested on a real machine.**
- Windows: tested by hand on three PCs (NVIDIA GTX 1080 Ti, Intel Core Ultra 7 155H, AMD Ryzen AI 7 350), not on many machines.
- **AMD GPU is experimental.** Only transcription runs on the GPU; **speaker separation (pyannote) still runs on the CPU**. Accuracy against the CPU engine, hallucinations on silent parts and 30+ minute meetings have **not** been measured. Only the Radeon 860M has been tried.
- **Intel GPU is experimental** (works on one Core Ultra 7 155H by manual check, not measured).
- The progress bar moves per stage (microphone, computer audio, speakers, merge), not within a stage, so on a long recording it can sit still for minutes while work continues.
- Real GitHub/GitLab/Google/S3 have only been tested against mock servers.
- Transcript/summary/task quality has not been measured widely. Review the output.
- Interface: Indonesian (default) and English. Generated summaries/tasks are Indonesian only.

## Roadmap (not implemented yet)
- AMD GPU: compare accuracy with the CPU engine, test a 30+ minute meeting, speaker separation on the GPU, progress inside a stage, then drop the "experimental" label. **Testers with other AMD machines are welcome** (open an issue).
- Measure and graduate the Intel GPU engine.
- Signed installers, a working Linux AppImage, a real-machine test of the Linux desktop app.
- More interface languages, and a choice of output language.

Report problems through Issues (do not attach recordings or API keys).

## Yang berubah
- **Lisensi:** Rekamind kini **AGPL-3.0-or-later** (seluruh repositori). Memakai, memasang, dan mengubahnya tetap gratis; bila Anda menjalankan versi yang diubah sebagai layanan jaringan, Anda wajib menyediakan kode sumbernya kepada pengguna layanan itu. Rilis sebelumnya diterbitkan dengan lisensi MIT. Komponen pihak ketiga dan atribusi model ada di [THIRD_PARTY_NOTICES.md](https://github.com/handokoaji/rekamind/blob/master/THIRD_PARTY_NOTICES.md).
- **Diperbaiki:** di AMD, **Uji mesin** menulis "Tidak ada perangkat Vulkan; memakai CPU" padahal transkripsi sungguhan memakai GPU. Tombol uji tidak bisa melihat GPU karena log whisper.cpp dimatikan; kini ia melaporkan perangkatnya (mis. `AMD Radeon(TM) 860M Graphics`).
- **Diuji (eksperimental, satu mesin):** GPU AMD lewat Vulkan di **Ryzen AI 7 350 (Radeon 860M, Windows 11)**. Rekaman nyata ±11 menit ditranskripsikan di GPU (`large-v3` q5_0): sekitar 3 menit untuk jalur suara komputer, GPU ±85% dan puncak RAM ±2,4 GB, dibaca dari Task Manager dan daftar proses. Log backend mencatat `whisper.cpp memakai GPU Vulkan: <nama>`.
- **Dokumen:** README (EN/ID) menyatakan status AMD dan batasannya secara apa adanya.

## Batasan yang diketahui
- Installer tidak bertanda tangan. **Linux desktop (baki, hotkey, audio) belum diuji di mesin sungguhan.**
- Windows: diuji manual di tiga PC (NVIDIA GTX 1080 Ti, Intel Core Ultra 7 155H, AMD Ryzen AI 7 350), belum di banyak mesin.
- **GPU AMD eksperimental.** Hanya transkripsi yang berjalan di GPU; **pemisah pembicara (pyannote) tetap di CPU**. Akurasi dibanding mesin CPU, halusinasi pada bagian hening, dan rapat 30+ menit **belum** diukur. Baru Radeon 860M yang dicoba.
- **GPU Intel eksperimental** (berjalan di satu Core Ultra 7 155H menurut pengecekan manual, belum diukur).
- Progress bar bergerak per tahap (mikrofon, suara komputer, pembicara, penggabungan), bukan di dalam satu tahap, jadi pada rekaman panjang bar bisa diam beberapa menit padahal proses berjalan.
- GitHub/GitLab/Google/S3 asli baru diuji dengan server tiruan.
- Kualitas transkrip/ringkasan/task belum diukur luas. Tinjau hasilnya.
- Antarmuka: Indonesia (bawaan) dan Inggris. Ringkasan/task yang dihasilkan hanya berbahasa Indonesia.

## Peta jalan (belum dikerjakan)
- GPU AMD: bandingkan akurasi dengan mesin CPU, uji rapat 30+ menit, pemisah pembicara di GPU, progres di dalam satu tahap, lalu lepas label "eksperimental". **Penguji dengan mesin AMD lain dipersilakan** (buka issue).
- Mengukur dan menaikkan status mesin GPU Intel.
- Installer bertanda tangan, AppImage Linux yang berfungsi, uji aplikasi desktop Linux di mesin nyata.
- Lebih banyak bahasa antarmuka, dan pilihan bahasa keluaran.

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
