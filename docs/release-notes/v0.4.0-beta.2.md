# Rekamind v0.4.0-beta.2

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

**Update from beta.1 if you record on Windows.** In beta.1 the recorder kept only about 10% of the audio (the rest was filled with
silence), so recordings sounded choppy and transcripts came out empty ("Tidak ada ucapan terdeteksi"). beta.2 fixes this. Recordings
made with beta.1 cannot be repaired.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.2-cpu` (CPU), `-cuda` (NVIDIA GPU), or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Fixed:** Windows recorder dropped ~90% of the audio. Verified on one PC: a 244 s recording went from 22% to 98% of frames containing sound, and the large-v3 transcript on the NVIDIA GPU came out with 72 correct Indonesian segments instead of none.
- **Fixed:** installing the NVIDIA engine with speaker separation could stall at ~0.01 MB/s (pip was sent to `pypi.nvidia.com`). The fix has been checked with a dry run only; **a cold-cache install has not been re-tested yet**.
- **Fixed:** engine install crashed with `OSError: [Errno 22]` / exit code 120 on Windows. Reproduced in Windows CI with the old build and verified fixed; an install with speaker separation also completed on a real PC.
- **Fixed:** Intel GPU engine install failed with `ResolutionImpossible`.
- **New (experimental):** Intel GPU (OpenVINO) and AMD GPU (Vulkan / whisper.cpp) engines.
- **New:** speaker-count hint per meeting; sentences spoken by two people are cut at the voice change; a "Dengarkan rekaman" card plays the recording even when the transcript is empty; a focused screen while recording; a download progress bar for the engine install; step-by-step guide for API keys (`docs/API_KEYS.md`).
- **Fixed:** a meeting with no tasks no longer stays in *Perlu ditinjau*; an empty summary answer is retried and then reported as an error instead of saved as done; the audio player now works in the desktop app.

## Known limitations
- Installers are unsigned. **Linux desktop (tray, hotkey, audio) has not been tested on a real machine.**
- Windows: tested on one PC (Windows 11, GTX 1080 Ti).
- **GPU:** CPU and NVIDIA CUDA are supported. **Intel GPU is experimental:** it works on one Core Ultra 7 155H according to a manual check, but speed and accuracy have not been measured. **AMD GPU is experimental and has not been run on real hardware** (the first test machine is a Ryzen AI 7 350). Other machines run on the CPU.
- Microphone level: if your microphone is nearly silent in recordings, check mute/gain in Windows; the app cannot fix a silent device.
- Real GitHub/GitLab/Google/S3 have only been tested against mock servers.
- Transcript/summary/task quality has not been measured widely. Review the output.
- Interface: Indonesian (default) and English. Generated summaries/tasks are Indonesian only.

## Roadmap (not implemented yet)
- Measure and graduate the Intel GPU engine; test the AMD GPU engine on real hardware.
- Signed installers, a working Linux AppImage, a real-machine test of the Linux desktop app.
- More interface languages, and a choice of output language.

Report problems through Issues (do not attach recordings or API keys).

# Bahasa Indonesia

**Perbarui dari beta.1 bila Anda merekam di Windows.** Di beta.1 perekam hanya menyimpan sekitar 10% audio (sisanya diisi senyap), sehingga
rekaman terdengar patah-patah dan transkrip kosong ("Tidak ada ucapan terdeteksi"). beta.2 memperbaikinya. Rekaman yang dibuat dengan
beta.1 tidak bisa diperbaiki.

## Unduh

| Sistem | Berkas |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, distro lain | `Rekamind-Linux-x64.AppImage` (hanya bila terlampir; build AppImage sejauh ini belum berhasil) |

**Image server (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.2-cpu` (CPU), `-cuda` (GPU NVIDIA), atau tanpa akhiran (hanya API).

Verifikasi dengan `SHA256SUMS.txt`. **Installer belum bertanda tangan.** Windows SmartScreen akan memperingatkan: *More info → Run anyway*.

## Yang berubah
- **Diperbaiki:** perekam Windows membuang ±90% audio. Terverifikasi di satu PC: rekaman 244 dtk naik dari 22% menjadi 98% frame yang berisi suara, dan transkrip large-v3 di GPU NVIDIA menghasilkan 72 segmen Indonesia yang benar, bukan kosong.
- **Diperbaiki:** memasang mesin NVIDIA dengan pemisah pembicara bisa macet di ±0,01 MB/s (pip diarahkan ke `pypi.nvidia.com`). Perbaikan baru diperiksa lewat dry run; **pemasangan dengan cache dingin belum diuji ulang**.
- **Diperbaiki:** pemasangan mesin gagal dengan `OSError: [Errno 22]` / kode keluar 120 di Windows. Direproduksi di CI Windows dengan build lama dan terbukti beres; pemasangan dengan pemisah pembicara juga selesai di PC nyata.
- **Diperbaiki:** pemasangan mesin GPU Intel gagal dengan `ResolutionImpossible`.
- **Baru (eksperimental):** mesin GPU Intel (OpenVINO) dan GPU AMD (Vulkan / whisper.cpp).
- **Baru:** petunjuk jumlah pembicara per rapat; kalimat yang diucapkan dua orang dipotong di pergantian suara; kartu "Dengarkan rekaman" memutar rekaman walau transkrip kosong; layar fokus saat merekam; bilah progres unduhan saat memasang mesin; panduan kunci API (`docs/API_KEYS.id.md`).
- **Diperbaiki:** rapat tanpa task tidak lagi tersangkut di *Perlu ditinjau*; jawaban ringkasan yang kosong diulang lalu dilaporkan sebagai galat, bukan disimpan sebagai selesai; pemutar audio kini berfungsi di aplikasi desktop.

## Batasan yang diketahui
- Installer tidak bertanda tangan. **Linux desktop (baki, hotkey, audio) belum diuji di mesin sungguhan.**
- Windows: diuji di satu PC (Windows 11, GTX 1080 Ti).
- **GPU:** CPU dan NVIDIA CUDA didukung. **GPU Intel eksperimental:** berjalan di satu Core Ultra 7 155H menurut pengecekan manual, tetapi kecepatan dan akurasi belum diukur. **GPU AMD eksperimental dan belum dijalankan di perangkat keras nyata** (mesin uji pertama: Ryzen AI 7 350). Komputer lain berjalan di CPU.
- Level mikrofon: bila mikrofon nyaris senyap di rekaman, periksa mute/gain di Windows; aplikasi tidak bisa memperbaiki perangkat yang senyap.
- GitHub/GitLab/Google/S3 asli baru diuji dengan server tiruan.
- Kualitas transkrip/ringkasan/task belum diukur luas. Tinjau hasilnya.
- Antarmuka: Indonesia (bawaan) dan Inggris. Ringkasan/task yang dihasilkan hanya berbahasa Indonesia.

## Peta jalan (belum dikerjakan)
- Mengukur dan menaikkan status mesin GPU Intel; menguji mesin GPU AMD di perangkat keras nyata.
- Installer bertanda tangan, AppImage Linux yang berfungsi, uji aplikasi desktop Linux di mesin nyata.
- Lebih banyak bahasa antarmuka, dan pilihan bahasa keluaran.

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
