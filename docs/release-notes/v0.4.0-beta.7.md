# Rekamind v0.4.0-beta.7

🌐 **English** · [Bahasa Indonesia](#bahasa-indonesia)

The summary now tells you what a meeting was about, not only how it went: **key points**, and **every topic with where it ended up**
(decided, still open, or raised and never picked up again), which is what you want after a meeting that wandered. The app also got a
few quiet improvements, and the server fixes below come from running beta.6 on a real GPU server.

## Download

| System | File |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, other distros | `Rekamind-Linux-x64.AppImage` (only if attached; the AppImage build has not been working so far) |

**Server image (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.7-cpu` (CPU), `-cuda` (NVIDIA GPU), `-cuda-diarize` (NVIDIA GPU + speaker separation), or without suffix (API only).

Verify with `SHA256SUMS.txt`. **The installers are unsigned.** Windows SmartScreen will warn: *More info → Run anyway*.

## What changed
- **Summary: key points and topics.** New "Poin penting" (the few things to remember) and "Topik yang dibahas" (each subject with a status, the times it was discussed, and what is still to do) next to "Keputusan" and the time-ordered "Jalannya rapat". Also in the Word, Markdown and JSON exports. A section with nothing in it now says so instead of disappearing.
- **Decisions are defined in the prompt now** (agreements and conclusions count even when nobody says "we decide"; an unaccepted proposal does not). Tasks also cover directions given by whoever chairs the meeting. On a long meeting the parts of the transcript are joined by one small extra call, so a subject that came back later is one topic with its final status.
- **Update notice that works behind a shared address.** GitHub's API allows 60 anonymous calls an hour per address and a campus shares one; the app now falls back to the public releases feed. (Beta.5 and beta.6 keep the old behaviour: to get the update notice reliably, install this version by hand once.)
- **Meeting list: the newest 10 with real pagination** ("Halaman 2 dari 3"), a page per browser history entry.
- **Light / dark / follow-system setting** (Settings > Tampilan; default follows the system).
- **Credit for the author**: a small "Tentang Rekamind" card in Settings, one muted line at the foot of the pages and on the sign-in screen. Text and icons only.
- **Desktop app shows the Google profile picture** (its content security policy blocked it).
- **Server: model downloads that crawl are cut off and retried.** Hugging Face's CDN had a node serving 0.1 MB/s; downloads sat on it for ever and the first transcription never finished. Now a download slower than 0.5 MB/s for 10 s is dropped and resumed (`REKAMIND_HF_MIN_MBPS`, 0 = off).
- **Server: a daily LLM quota fails at once with a clear message** (it used to retry for about four minutes), and the tokens each summary used are logged.
- The compose files default `REKAMIND_BIND` to `0.0.0.0` since beta.6; nothing new to set. **The database gains two columns by itself at start-up (migration 0005); keep a backup of a database you care about.**

## Known limitations
- **Uploads over 100 MB fail behind Cloudflare's free plan** (it answers 413), and so does a desktop recording longer than about 52 minutes (the recorder writes about 115 MB per hour). A server not behind such a proxy is unaffected. Workaround for a video: extract the audio first, e.g. `ffmpeg -i meeting.mp4 -vn -c:a copy audio.m4a` (a 455 MB, 2 h 9 min recording became 55 MB). Chunked upload is not built yet.
- **The summary service has a daily token quota on free plans** (Groq: 200,000 tokens a day per model). One long meeting is many calls; several in a day can run it out. Use "Buat ulang ringkasan" once the quota returns, a paid plan, or your own model.
- **Judge the topics on your own meetings.** They were checked on one invented transcript and one real 28-minute meeting; the number of tasks varied between runs on the same transcript; a two-hour meeting was processed (16 minutes, VRAM 8.5 GB peak) but the new summary code was not run on it before release.
- The in-app updater downloads and verifies the installer, but running it and restarting the app has not been tested end to end. If the app does not reopen by itself, start it from the Start menu.
- The `-cuda-diarize` image is about 11 GB. Installers are **unsigned**. Linux desktop and the AppImage are untested/not working, as before. Everything under the limitations of v0.4.0-beta.4 still applies.

Report problems through Issues (do not attach recordings or API keys).

# Bahasa Indonesia

Ringkasan kini menjelaskan rapat itu membahas apa, bukan hanya jalannya: **poin penting**, dan **setiap topik beserta akhirnya** (diputuskan,
masih terbuka, atau diangkat lalu tidak dilanjutkan), yang berguna setelah rapat yang melompat-lompat. Aplikasi juga mendapat beberapa
perbaikan kecil, dan perbaikan server di bawah berasal dari menjalankan beta.6 di server GPU sungguhan.

## Unduh

| Sistem | Berkas |
|---|---|
| Windows 10/11 64-bit | `Rekamind-Windows-x64-setup.exe` |
| Linux 64-bit (Debian/Ubuntu) | `Rekamind-Linux-x64.deb` |
| Linux, distro lain | `Rekamind-Linux-x64.AppImage` (hanya bila terlampir; build AppImage sejauh ini belum berhasil) |

**Image server (GHCR):** `ghcr.io/handokoaji/rekamind-server:0.4.0-beta.7-cpu` (CPU), `-cuda` (GPU NVIDIA), `-cuda-diarize` (GPU NVIDIA + pemisah pembicara), atau tanpa akhiran (hanya API).

Verifikasi dengan `SHA256SUMS.txt`. **Installer belum bertanda tangan.** Windows SmartScreen akan memperingatkan: *More info → Run anyway*.

## Yang berubah
- **Ringkasan: poin penting dan topik.** Ada "Poin penting" (hal yang perlu diingat) dan "Topik yang dibahas" (tiap pokok bahasan dengan status, waktu dibahas, dan tindak lanjutnya) di samping "Keputusan" dan "Jalannya rapat" yang berurutan waktu. Ikut di ekspor Word, Markdown, dan JSON. Bagian yang kosong kini bertuliskan kosong, tidak lagi menghilang.
- **Keputusan kini didefinisikan di prompt** (kesepakatan dan kesimpulan dihitung walau tidak ada yang mengucap "kita putuskan"; usulan yang tidak disetujui tidak). Task juga mencakup arahan pimpinan rapat. Pada rapat panjang, bagian-bagian transkrip digabung satu panggilan tambahan kecil, jadi topik yang dibahas lagi di akhir menjadi satu topik dengan status akhirnya.
- **Pemberitahuan pembaruan yang tahan di alamat bersama.** API GitHub membatasi 60 panggilan per jam per alamat, dan kampus memakai satu alamat bersama; aplikasi kini beralih ke feed rilis publik. (Beta.5 dan beta.6 tetap berperilaku lama: pasang versi ini secara manual sekali agar pemberitahuan andal.)
- **Daftar rapat: 10 terbaru dengan paginasi sungguhan** ("Halaman 2 dari 3"), satu halaman satu entri riwayat browser.
- **Pengaturan terang / gelap / ikuti sistem** (Pengaturan > Tampilan; bawaannya mengikuti sistem).
- **Kredit penulis**: kartu "Tentang Rekamind" di Pengaturan, satu baris redup di kaki halaman dan di layar masuk. Hanya teks dan ikon.
- **Aplikasi desktop menampilkan foto profil Google** (sebelumnya diblokir kebijakan keamanan konten).
- **Server: unduhan model yang merayap diputus dan diulang.** CDN Hugging Face punya satu node yang melayani 0,1 MB/s; unduhan menempel di sana selamanya sehingga transkripsi pertama tidak pernah selesai. Kini unduhan di bawah 0,5 MB/s selama 10 detik diputus dan dilanjutkan (`REKAMIND_HF_MIN_MBPS`, 0 = mati).
- **Server: kuota harian LLM langsung gagal dengan pesan jelas** (dulu mengulang sekitar empat menit), dan token yang dipakai tiap ringkasan dicatat di log.
- Berkas compose memakai `REKAMIND_BIND=0.0.0.0` sejak beta.6; tidak ada yang baru untuk diisi. **Basis data menambah dua kolom sendiri saat server start (migrasi 0005); buat cadangan untuk basis data yang penting.**

## Batasan yang diketahui
- **Unggahan di atas 100 MB gagal di balik paket gratis Cloudflare** (dijawab 413), termasuk rekaman desktop lebih dari ±52 menit (perekam menulis sekitar 115 MB per jam). Server yang tidak di balik proxy seperti itu tidak terpengaruh. Jalan keluar untuk video: ambil audionya dulu, mis. `ffmpeg -i rapat.mp4 -vn -c:a copy audio.m4a` (rekaman 455 MB, 2 jam 9 menit menjadi 55 MB). Unggah bertahap belum dibuat.
- **Layanan ringkasan punya kuota token harian di paket gratis** (Groq: 200.000 token per hari per model). Satu rapat panjang berarti banyak panggilan; beberapa dalam sehari bisa menghabiskannya. Gunakan "Buat ulang ringkasan" setelah kuota pulih, paket berbayar, atau model Anda sendiri.
- **Nilai topik pada rapat Anda sendiri.** Baru diperiksa pada satu transkrip buatan dan satu rapat nyata 28 menit; jumlah task berubah antar-jalan pada transkrip yang sama; rapat dua jam sudah diproses (16 menit, puncak VRAM 8,5 GB) tetapi kode ringkasan baru belum dijalankan padanya sebelum rilis.
- Pembaruan dalam aplikasi mengunduh dan memverifikasi installer, tetapi menjalankannya dan membuka ulang aplikasi belum diuji dari awal sampai akhir. Bila aplikasi tidak terbuka sendiri, buka dari menu Start.
- Image `-cuda-diarize` sekitar 11 GB. Installer **belum bertanda tangan**. Desktop Linux dan AppImage belum diuji/belum berfungsi, seperti sebelumnya. Semua batasan pada v0.4.0-beta.4 masih berlaku.

Laporkan masalah lewat Issues (jangan lampirkan rekaman atau kunci API).
